# 📚 Library Management System

A Python command-line application to manage a library's books, borrowing, and returning system.

## Features
- Add books to the library
- Borrow and return books
- Search books by title or author
- View all books or only available books
- Data stored permanently using SQLite database
- Duplicate book prevention with UNIQUE constraint
- Full error handling for smooth user experience

## Technologies Used
- Python
- SQLite3 (built-in Python library)
- JSON (earlier version used File I/O)
- Error handling with try/except

## Skills Demonstrated
- SQLite database operations (CREATE, INSERT, SELECT, UPDATE, DELETE)
- CRUD operations
- SQL queries with WHERE and LIKE
- Tuple unpacking
- Input validation
- Modular function design

## How to Run
1. Make sure you have Python installed
2. Run the notebook in Jupyter
3. Follow the on-screen menu to manage your library

## Project Evolution
This project was progressively upgraded through:
1. Basic dictionary-based storage
2. File I/O with JSON for data persistence
3. Error handling with try/except
4. SQLite database for professional data management
